## Blockers

1. **Test suites write a cert and private key into the real `~/.haltija/certs` and reach for the real 8701.**
   - `src/playwright-server.ts` opts out with `DEV_CHANNEL_NO_HTTPS=1`, which nothing has read since v0.1.7.
   - `src/server-autoport.test.ts` builds its env by hand.
   - Under the new `both` default, every e2e server binds 8701 if it is free, capturing the machine's https tabs.
     Otherwise it prints "HTTPS DOWN".
   - The `unit-tests.yml` footprint gate does not check `certs`, and `e2e.yml` has no gate. (correctness M1 is the
     same finding.)
2. **Every non-private server claims the well-known HTTPS 8701, not just the one holding 8700.**
   - Affected: a `--port`/`--name` server, or one bumped off a busy 8700 onto an ephemeral port.
   - Such a server captures every project's https pages while the 8700 server and `hj` see 0 tabs. It is first to
     boot wins — the #32 silent-misroute class, now reached by the default.

## Major

- **Security:** any web page can drive `/eval`, `/tree`, `/events`, `/screenshot` and `/shutdown` and read the results.
  - REST sends `Access-Control-Allow-Origin: *` and `Allow-Private-Network: true`, with no token by default.
  - HTTPS-by-default widens this to https pages in Safari, which WebKit's mixed-content block used to stop.
  - Pre-existing, and tracked as GitHub #44. Needs an owner decision before 1.13.0.
- **Correctness:** the startup banner, the DEV MODE one-liner and the exported `server` prefer the self-signed HTTPS
  URL. `curl https://localhost:8701/docs` fails on the openssl cert, and the one-liner fails silently on http pages
  until the cert is accepted.
- **Correctness:** `testInBrowser` `clickAt`/`dragFrom` dispatch only MouseEvents, with no pointer events and no
  `buttons`, while the header comment claims haltija's actionability handling. Pointer-driven drags (3D camera
  controls) can silently no-op.
- **Blast radius + security + correctness:** the machine-level cert is never checked for expiry. openssl issues it
  for 365 days, and nothing regenerates it any more.
- **Blast radius:** cert generation and adoption write a private key into `$HOME` with no receipt, announced on stdout
  only.
- **Blast radius:** `publish.yml` has already drifted from `templates/publish.yml`. Upstream aa1f6d0 moved
  `attest.ts --verify-shipped` after Pack and gave it the tarball, so this copy fails closed on any attested tag.

## Refuted (kept for the record)

- HTTPS bypasses the machine-control 410. It does not: both listeners share one handler.
- The adopted key is left world-readable. It is not: `chmod 0600` runs after the copy.
- freePort(8701) shuts down a bystander `--both` server. It does not: the bystander is unidentified and the request
  is declined.
- HTTPS-by-default slows startup. It does not: ~80ms in both modes.
- Cert keygen runs every start. It does not: once per machine.
- Loader snippet leaves the failed tag behind. It does not: `s.remove()` runs before the fallback.
- `ListeningServer` types lie. They do not: the fields match, and the nullability is right.
